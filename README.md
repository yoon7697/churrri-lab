# CHURRRI’S LAB — 포트폴리오 전용 v1.1

게임별 저장소·사이트를 독립적으로 운영하고, 포트폴리오에는 링크를 모으는 버전입니다.

## 사이트 구분

| 역할 | 주소 |
| --- | --- |
| 포트폴리오 | https://churrri-lab.vercel.app/ |
| 우리 반 오목왕 | https://churrri-omok.vercel.app/ |

오목왕 실행 링크 4개(이미지, 작품명, 바로 실행, 사용법 팝업의 실행 버튼)는 모두 오목왕 사이트를 새 탭으로 엽니다.
게임 코드는 이 패키지에 포함하지 않습니다. assets/omok-preview.webp는 포트폴리오 카드에 보여줄 썸네일 이미지입니다.

## GitHub 업로드 방법

1. 이번 ZIP의 압축을 풉니다. ZIP 파일 자체를 올리지 않습니다.
2. **포트폴리오용 기존 저장소**의 최상위에 아래 6개 파일과 assets 폴더를 올립니다.
   - index.html
   - style.css
   - script.js
   - favicon.svg
   - vercel.json
   - README.md
   - assets/ (안의 omok-preview.webp 포함)
3. 같은 이름의 기존 파일을 교체한 후 Commit changes를 누릅니다.
4. index.html이 저장소 최상위에 있는지 확인합니다. 바깥 폴더째 업로드하지 않습니다.
5. 기존 Vercel 배포 결과를 확인합니다.

아직 이전 통합본을 올리지 않았다면 이번 ZIP만 사용하세요.
이미 이전 통합본을 올렸다면 위 파일들을 교체하고 **포트폴리오 저장소 안의 omok 폴더**를 삭제하세요.
삭제 대상은 포트폴리오에 복사된 폴더뿐입니다. 별도 오목왕 저장소와 Vercel 프로젝트는 그대로 둡니다.
옛 content.js는 이 버전에서 사용하지 않습니다. 남아 있어도 화면에 영향을 주지 않습니다.

## Vercel 설정

Framework Preset은 Other, Root Directory는 저장소 최상위, Build Command는 비워 둡니다.
이 패키지의 vercel.json은 빌드 없이 최상위 파일을 배포하도록 설정합니다.
기존 GitHub 저장소와 Vercel 프로젝트가 연결돼 있다면 그 연결을 그대로 사용합니다.

## 앞으로 작품을 추가하는 방법

게임은 각자의 GitHub 저장소와 Vercel 프로젝트에서 수정하고 배포합니다.
포트폴리오에는 index.html에 소개 카드와 해당 게임의 공개 주소를 추가하고, 필요하면 assets에 미리보기 이미지를 넣습니다.
검색이 새 카드를 찾게 하려면 data-category와 data-search를 함께 지정하고 전체 개수 표시를 갱신합니다.
게임을 업데이트해도 공개 주소가 같다면 포트폴리오 링크를 바꿀 필요가 없습니다.

## 확인할 내용

- 카드 이미지가 보이는지
- 검색·분류와 사용법 팝업이 작동하는지
- 카드의 바로 실행을 누르면 새 탭에서 churrri-omok.vercel.app이 열리는지
- 교실 퀴즈 게임이 기획 중으로 표시되는지

현재 연락 버튼은 연락 채널 준비 중 안내만 표시하며 의견을 전송하지 않습니다.
