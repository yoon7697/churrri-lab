# CHURRRI'S LAB 포트폴리오 사이트

## 열어보기
`index.html` 파일을 더블클릭하면 브라우저에서 미리보기가 열립니다.

## 콘텐츠 업데이트
`content.js` 파일을 열어 `projects` 배열에 프로젝트를 추가하세요. `title`, `category`(수업 도구 / 학급 운영 / 제작 기록), `status`(기획 중 / 제작 중 / 공개), `description`, `url`을 입력하세요. 실제 완료하지 않은 작품은 반드시 진행 상태를 구분하세요.

`notion`에는 노션 공개 페이지 주소를, `email`에는 공개용 연락처를 입력하세요. 개인정보가 담긴 학생 자료는 올리지 마세요.

## Vercel에 공개하기
1. GitHub에서 새 공개 저장소를 만들고 이 폴더의 4개 파일(`index.html`, `style.css`, `content.js`, `script.js`)을 업로드하세요.
2. Vercel에서 `Add New → Project`로 GitHub 저장소를 가져오세요.
3. Framework Preset은 `Other`, Build Command는 비워두고 배포하면 됩니다.
4. 배포 후 사이트 주소를 노션의 웹사이트 항목에 붙여넣으세요.

## 참고
제공된 참고 사이트의 구조(교사 개발자 소개 + 프로젝트 아카이브)만 참고하여 독립적인 색상·레이아웃·콘텐츠로 제작했습니다. 별도 서버와 개인 데이터 수집 없이 작동합니다.
