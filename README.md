## 실제 메일 전송을 켜는 방법 — 최초 1회

주소를 입력하는 것만으로는 네이버 계정에서 메일을 보낼 수 없습니다.
현재 파일에는 계정 비밀번호가 전혀 들어 있지 않습니다.

1. 네이버 메일 PC 화면에서 환경설정 → POP3/IMAP 설정으로 이동합니다.
2. SMTP를 사용할 수 있도록 설정합니다. 네이버 공식 안내에 따라 2단계 인증과 애플리케이션 비밀번호를 준비합니다.
3. Vercel에서 **포트폴리오 프로젝트** → Settings → Environment Variables에 아래 값을 추가합니다.

| 이름 | 값 |
| --- | --- |
| SMTP_USER | yoon76971@naver.com |
| NAVER_SMTP_PASSWORD | 네이버에서 발급한 애플리케이션 비밀번호 |

4. Production에 적용하고, 미리보기에서도 실제 발송을 쓸 경우 Preview에도 적용합니다.
5. 환경 변수 저장 후 해당 프로젝트를 Redeploy 합니다.
6. 배포한 포트폴리오에서 아이디어 나누기를 열고 짧은 메시지를 직접 보내 네이버 받은편지함과 스팸함을 확인합니다.

**비밀번호는 채팅이나 GitHub 파일에 쓰지 말고 Vercel 환경 변수에만 입력하세요.**
네이버 SMTP 서버는 smtp.naver.com, SSL 포트는 465로 코드에 설정돼 있습니다.

공식 안내:
- https://help.naver.com/service/30029/contents/21340?osType=PC
- https://help.naver.com/service/30029/contents/21351?osType=COMMONOS
- https://vercel.com/docs/functions/runtimes/node-js

## 전송 동작

- 수신자는 yoon76971@naver.com으로 고정됩니다.
- 발신자는 설정된 네이버 계정이며, 방문자 이메일은 답장 주소(Reply-To)로 설정합니다.
- 네이버 메일 서버가 수신자를 받아들였을 때만 전송 접수 안내를 표시합니다. 스팸 분류나 실제 받은편지함 도착까지 보장하는 뜻은 아닙니다.
- SMTP 설정 전에는 전송 완료라고 표시하지 않고 메일 연결 준비 중 안내를 표시합니다.
- 메일 앱으로 직접 보내기는 별도로 사용할 수 있습니다. 작성한 제목·내용을 메일 앱에 넘기며, 앱에서 전송 버튼을 눌러야 합니다.
- 방문자 입력은 서버 데이터베이스나 브라우저 저장소에 별도 저장하지 않습니다. 이메일은 네이버 메일함에 보관됩니다.
- 메일 본문이나 비밀번호를 서버 로그에 기록하지 않습니다.
- 기본 입력 검증, 숨김 스팸 필드, 동일 출처 검사, 서버 인스턴스 단위 1분 간격 제한이 있습니다. 분산 환경 전체에 대한 강력한 봇 차단은 아닙니다.
